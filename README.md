# Andrea Punctuality OS™

Sistema certificato per arrivare alle 10:00 a studiare. Single-file HTML, zero dipendenze, zero backend.

## Come si usa

Apri `index.html` in qualsiasi browser (anche dal telefono).

- Live countdown alle 10:00
- Classificatore di scuse (categoria, similarità, credibility 0-100)
- Bingo della puntualità (12 caselle)
- Cronologia ritardi dal 17 marzo 2026 (11 voci)
- Hall of Shame (top 3 più assurde)
- Streak di giorni in tempo (LocalStorage)

## Distribuzione

Inoltra `index.html` ad Andrea via WhatsApp/Telegram/Email. Lo apre, lo aggiunge alla home screen del telefono come web app.
